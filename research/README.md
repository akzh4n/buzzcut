# research

Не часть плагина. Анализатор компакции из предыдущей итерации проекта:
измеряет, что переживает `/compact` в транскриптах Claude Code.

Результат измерения на 53 компакциях: из 756 выброшенных границей указаний
пользователя язык ограничения содержат 4 (0.5%). То есть промпт компакции
сохраняет указания заметно лучше, чем принято думать.

Оставлено как доказательная база под статью.

    python3 -m pytest research/tests -q
